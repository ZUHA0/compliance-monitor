
# 🚀 Automated Compliance Monitoring System

## 📌 Problem Statement
Manual compliance checks are error-prone, slow, and inefficient.
Organizations need continuous monitoring of system logs to detect policy violations.

---

## 💡 Our Solution
A Python-based Automated Compliance Monitoring System that:

- Reads system logs
- Applies rule-based compliance checks
- Detects violations automatically
- Provides REST API access
- Displays real-time dashboard
- Cloud deployment ready

---

## 🛠️ Tech Stack

- Python
- Flask (REST API)
- Streamlit (Dashboard UI)
- Pandas (Log Analysis)
- JSON (Rule Engine)

---

## 🔍 Features

✔ Rule-based violation detection  
✔ Real-time compliance dashboard  
✔ REST API endpoint  
✔ Easy rule customization  
✔ Cloud deployable
